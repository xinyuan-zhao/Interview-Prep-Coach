# 中文面试准备教练

面向参加**中文面试的中文用户**。面试问题、答案、解释和反馈默认使用中文。

## 你需要准备什么

完整准备必需：

1. 你的简历 / Resume / CV。
2. 职位描述 / JD。

可选但很有帮助：

- 公司名称或招聘链接。
- 面试轮次、类型和日期。
- 面试官姓名或公开职业背景。
- 你已经写过的答案或面试笔记。

## 如何安装

下载或克隆本仓库，把 `interview-prep-coach-zh` 文件夹单独压缩成 zip，然后在支持 Agent Skills 格式的产品中上传/安装。请确保 `SKILL.md`、`agents/` 和 `references/` 保持在同一个 Skill 文件夹中。

## 如何开始

调用 `$interview-prep-coach-zh`，然后说：

> 帮我完整准备这场中文面试。这是我的简历和 JD。

如果不知道下一步做什么，只需要问：

> 我需要发给你什么？

## 示例指令

- 帮我分析这个 JD。
- 这个岗位最重要的三个能力是什么？
- 把我的经历和岗位要求匹配一下。
- 我应该准备哪几个核心故事？
- 帮我把这段经历整理成 STAR。
- 预测最可能问我的问题。
- 帮我准备英文 Tell me about yourself。
- 直接开始模拟面试。
- 像严格的 Hiring Manager 一样追问我。
- 每回答一题就给我反馈。
- 生成面试速查表。
- 我刚面试完，帮我复盘。

## 你会得到什么

- 岗位本质与核心能力分析。
- 简历 × JD 证据地图。
- Top 3 卖点和真实 Gap 定位。
- 3–5 个可复用 STAR 故事。
- 按优先级排序的面试题。
- 核心答案提纲或口语稿。
- 有连续追问和评分的模拟面试。
- 面试前 5–10 分钟速查表。
- 结构化面后复盘。

## 真实性与隐私提醒

本 Skill 不应编造工作经历、领导职责、工具、成果或数字。证据不足时，它会追问或标记 Gap。正式使用任何答案前，请自行核对事实。

简历可能包含个人信息。尽量只分享准备面试所需的内容，可先删除地址、电话、证件信息等敏感数据，并遵守你所在组织的数据政策。
